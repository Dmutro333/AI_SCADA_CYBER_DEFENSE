# AI SCADA Cyber Defense Platform

AI SCADA Cyber Defense Platform — навчально-демонстраційна програмна платформа для моделювання кіберзахисту SCADA/ICS середовища об’єкта критичної інфраструктури з використанням технологій штучного інтелекту.

## Основні можливості

- авторизація користувачів;
- SCADA/SOC Dashboard;
- Digital Twin модель умовної теплоелектроцентралі;
- AI Detection Engine на основі Random Forest;
- моделювання кібератак DDoS, PLC Manipulation, Replay Attack, Fake Sensor Data Injection, Database Attack;
- оцінювання ризику;
- автоматизоване реагування;
- SAFE MODE;
- журналювання подій;
- збереження результатів у SQLite.

## Технології

- Python 3.11
- PyQt5
- SQLite
- Scikit-learn
- Pandas
- NumPy
- Joblib
- Matplotlib
